# Live-items kill sheet — audience-first review

*JV · Sep 12 2026 · acceptance criteria for the four OFY live items*
*Rule (Naman): think from the other side's perspective when they see the public-facing work. Think like a killer.*

## PREDICTION — Depth Desk
**Viewer:** astrologer/practitioner deciding whether to white-label; private client.
**Their first-30s read must be:** "Audit trail, not an AI horoscope. This desk sits behind MY name and makes me look better."
**Controls:** sample dossier re-rendered anonymized (no real public figure, no client name); chain + QC + citations visible in the sample; CTA = request access for a real read.
**Kills:** predictive claims; celebrity names; stray internal brand marks in public copy (neutralize until a public desk mark is chosen by Naman).

## VOICE — Hinglish STT
**Viewer:** CTO/founder with Indian users; agency partner.
**Their first-30s read must be:** "Handles MY callers (noise, code-mix), runs cheap, and I can reproduce the numbers."
**Controls:** curated frozen set across levels (clean / noisy / code-mixed); real transcript excerpts incl. one honest limitation line; latency + per-hour CPU cost; fresh-clone TRYABLE; short demo recording.
**Kills:** raw run dumps; silence/junk takes; any clip that cannot be published — hard filter before anything ships.

## INDUSTRIAL — Spectral Match
**Viewer:** technical evaluator (credibility lane — kept cheap, not the rent path).
**Their first-30s read must be:** "Real remote-sensing engineering, honest numbers, runs today."
**Controls:** fresh-clone ritual passes; before/after classified-map visual; Cuprite scorecard WITH context ("honest baseline, not product accuracy"); provenance file visible.
**Kills:** overclaiming accuracy; gallery shots without a runnable path.

## CUSTOM — Build slots
**Viewer:** funded startup founder / agency partner (the 25-lead sends land here).
**Their first-30s read must be:** "They shipped something real for someone like me; starting is 3 lines of brief, low risk."
**Controls:** resto case unlocked (Naman: no term — usable) as system writeup + screenshots; brief template; one working intake path; replace bare "all work NDA" with "we show systems, not names."
**Kills:** NDA-wall with zero visible proof; generic "custom development" language.
